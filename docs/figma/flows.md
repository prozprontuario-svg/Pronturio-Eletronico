# Fluxos

- Principal: Login → Setembro Amarelo → Início → Pacientes → Prontuário → Triagem → Anotações de enfermagem → Nova anotação → Revisar anotação → Prontuário.
- Complementares: Prontuário → Exames / Prescrição / Histórico / Documentos / Saída hospitalar.
- Cirurgias: Início → Cirurgias → Detalhes → Prontuário.
- Revisões: preenchimento → revisão → corrigir ou confirmar → persistência → feedback → contexto do paciente.
- Mobile: TopBar/Mobile, cabeçalho do paciente, seletor de seção, navegação inferior e menu Mais.
- Esqueceu a senha aparece somente como link visual no login. Nenhum fluxo de recuperação é permitido nesta versão.
