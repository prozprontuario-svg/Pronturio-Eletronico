Como montar o arquivo

  1. Extraia o ZIP e abra um novo arquivo no Figma Desktop.
  2. Abra Plugins → Development → New Plugin. Escolha Figma Design → Run once e salve o plugin.
  3. Copie Importar-no-Figma/code.js para a pasta criada pelo Figma. Substitua apenas o code.js; preserve o manifest.json gerado.
  4. Execute o plugin pelo menu Plugins → Development.
  5. Após conferir, use File → Save local copy para obter o .fig.

Se o seu arquivo limitar o número de páginas, use code-compacto.js no lugar de code.js. A versão padrão cria as seis páginas solicitadas; a compacta cria uma única página.
