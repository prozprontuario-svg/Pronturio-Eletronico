# Proz Saúde

- Este repositório implementa um prontuário eletrônico hospitalar para localhost.
- Consulte `docs/PROJECT_SOURCE_OF_TRUTH.md` para regras permanentes e decisões locais.
- O Figma atual é a referência visual quando acessível; exceções explícitas do pedido prevalecem.
- Desktop e mobile devem oferecer funções clínicas equivalentes.
- Consulte `docs/figma/` quando alterar interface, fluxo ou comportamento correspondente.
- Preserve o design existente; não invente funções nem use dados reais de pacientes.
- Não faça deploy nem ative serviços externos.
- Mantenha autenticação, autorização, persistência e auditoria funcionais localmente.
